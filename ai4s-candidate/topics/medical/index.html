Reading Guide

Medical Image Analysis · Course Reading Guide

This seminar series covers six core directions in medical image analysis, with representative works selected from classic methods to frontier research, focusing on how technical paradigms evolve. The six sections are: medical image segmentation, medical image translation, medical image classification, medical object detection, 3D reconstruction in medical imaging, and medical image agents.

01

Medical Image Segmentation

4 papers

Medical image segmentation has evolved from task-specific deep network design, to data-driven self-configuration, to universal segmentation across tasks and modalities, and recently into the era of medical vision foundation models. The four papers selected for this section represent four stages — the U-Net base architecture, the self-configuring paradigm, universal segmentation, and the open-world foundation model — illustrating the shift from designing a model for a single task to building one model that adapts to many tasks and open-world scenarios.

Section Summary

U-Net → nnU-Net → UniverSeg → Open-world Foundation Model: this section traces how medical segmentation research has gradually shifted from asking how to design a better network to asking how to build a general model that generalizes to new tasks and new scenarios.

  1. 2015MICCAI

    U-Net: Convolutional Networks for Biomedical Image Segmentation

    PDF

    READING GUIDE

    U-Net is one of the most iconic works in medical image segmentation. Its symmetric encoder-decoder architecture with cross-level skip connections fuses high-level semantic information with low-level spatial detail. The core idea is simple yet effective, proving highly adaptable when medical data is limited and object boundaries are complex, and it has become the base architecture for a vast number of subsequent medical segmentation methods.

    Key Takeaway

    The key to medical image segmentation is not only understanding what something is, but also answering precisely where it is. U-Net innovatively resolves the tension between semantic understanding and spatial localization through multi-scale feature fusion.

  2. 2021Nature Methods

    nnU-Net: A Self-configuring Method for Deep Learning-based Biomedical Image Segmentation

    PDF

    READING GUIDE

    Instead of proposing a more complex segmentation network, nnU-Net systematically studies the impact of preprocessing, network configuration, training strategy and post-processing in medical image segmentation, and automatically configures the entire training pipeline for each dataset. It shows that a systematically configured, standardized pipeline achieves remarkably strong performance across a wide range of medical segmentation tasks.

    Key Takeaway

    The performance of medical AI depends not only on network architecture; data processing, training strategy and experimental configuration matter just as much. The research paradigm begins to shift from designing more complex models to building more reliable automated methods.

  3. 2023ICCV

    UniverSeg: Universal Medical Image Segmentation

    PDF

    READING GUIDE

    UniverSeg goes beyond the one-dataset-one-model paradigm: a small support set of examples allows the model to directly perform predictions on unseen medical segmentation tasks without retraining. It demonstrates the shift from dataset-level generalization to task-level generalization in medical image segmentation.

    Key Takeaway

    A truly universal model should not merely achieve high performance on multiple datasets; it should adapt quickly to new tasks through only a few examples.

  4. 2025Nature Biomedical Engineering

    A Generalist Foundation Model and Database for Open-world Medical Image Segmentation

    PDF

    READING GUIDE

    This work targets open-world medical image segmentation, building a large-scale segmentation database and a generalist foundation model capable of handling far more diverse medical tasks, with explicit attention to out-of-distribution data and generalization in real clinical scenarios. It pushes medical image segmentation from multi-task generalization further toward an open-world medical vision foundation model.

    Key Takeaway

    The key value of a foundation model is not merely covering more data and tasks, but retaining reliable generalization when facing unknown distributions and open scenarios.

02

Medical Image Translation

4 papers

Medical image translation concerns generating one form of medical image or staining from another. Its paradigm has gradually evolved from conventional visual domain transfer into generation tasks with explicit biomedical meaning. Centered on virtual histological staining, this section traces the progression from Virtual Staining → Special Stain → Virtual Multiplexing → Virtual Population.

Section Summary

Virtual Staining → Special Stain Translation → Virtual Multiplexing → Virtual Population: this section captures an important shift for generative AI in medicine — from generating visually realistic images to generating information with biological and clinical significance.

  1. 2019Nature Biomedical Engineering

    Virtual Histological Staining of Unlabelled Tissue-autofluorescence Images via Deep Learning

    PDF

    READING GUIDE

    This work uses autofluorescence images of unstained tissue to generate virtual histological staining results with deep learning, replacing the traditional physical staining process computationally. Its core significance lies in proving that deep learning can convert unstained tissue into histologically meaningful virtual stains, laying an important foundation for virtual pathology staining.

    Key Takeaway

    Image translation can go beyond visual similarity: it can simulate experimental procedures and acquire new medical information.

  2. 2021Nature Communications

    Deep Learning-based Transformation of H&E Stained Tissues into Special Stains

    PDF

    READING GUIDE

    This work advances virtual staining from unstained-tissue-to-H&E to H&E-to-special-stains, generating PAS, Masson's Trichrome, Jones and other special staining results. Beyond mere image style transfer, it further demonstrates the potential diagnostic value of virtual staining in pathology.

    Key Takeaway

    Virtual pathology staining begins to move from replacing physical staining toward expanding diagnostic information.

  3. 2024Nature Machine Intelligence

    Accelerating Histopathology Workflows with Generative AI-based Virtually Multiplexed Tumour Profiling

    PDF

    READING GUIDE

    Virtual Multiplexer generates multiple virtual IHC markers from a single H&E image, simulating multiplexed molecular assays, and further uses these virtual markers for tumor phenotyping. It connects image generation with tumor biology analysis, extending virtual staining from producing a single stain to joint multi-marker analysis.

    Key Takeaway

    Generative models are not merely generating images here — they attempt to infer latent molecular and biological states from morphological information.

  4. 2026Cell

    Multimodal AI Generates Virtual Population for Tumor Microenvironment Modeling

    PDF

    READING GUIDE

    This work extends generative medical image analysis to population and microenvironment modeling, using multimodal AI to generate biologically meaningful virtual tumor microenvironments and virtual patient populations. The goal has moved beyond single-image translation: generative models are used to construct new biomedical data spaces for tumor microenvironment research.

    Key Takeaway

    The ultimate value of medical image translation may not be a photorealistic image, but the generation of new biomedical data that can be used for scientific research.

03

Medical Image Classification

4 papers

Medical image classification is one of the earliest tasks where medical AI achieved notable breakthroughs. Its research has evolved from supervised learning for a single disease, to large-scale weakly supervised learning, and on to foundation models and trustworthy medical AI. This section highlights the progression: Task-specific Classification → Weakly-supervised Clinical AI → Foundation Model → Auditable Foundation Model.

Section Summary

Task-specific Classification → Weakly-supervised Clinical AI → Foundation Model → Auditable Foundation Model: this section reflects the evolution of the field's central questions — Can AI diagnose at all? How can clinical data be used at low cost? How can one model serve many tasks? And how can a foundation model be made trustworthy?

  1. 2017Nature

    Dermatologist-level Classification of Skin Cancer with Deep Neural Networks

    PDF

    READING GUIDE

    This work trains a deep neural network on a large corpus of skin disease images and compares its results with dermatologists, demonstrating the clinical potential of deep learning for skin cancer classification. A classic in deep learning for medical imaging, it marks the field's move from laboratory tasks toward clinical-grade diagnostic problems.

    Key Takeaway

    Deep learning can not only achieve high accuracy on medical image classification benchmarks, but also has the potential to reach the level of specialist physicians.

  2. 2019Nature Medicine

    Clinical-grade Computational Pathology Using Weakly Supervised Deep Learning on Whole Slide Images

    PDF

    READING GUIDE

    To address the prohibitive annotation cost of whole-slide images, this work performs weakly supervised learning with slide-level diagnoses, learning cancer-related representations directly from entire slides via Multiple Instance Learning. It proves that large-scale weakly labeled data can train pathology AI with clinical-grade performance.

    Key Takeaway

    The core bottleneck of medical AI is not only the model, but also data annotation; weakly supervised learning offers an important path to exploiting massive real-world clinical data.

  3. 2023NatureRETFound

    A Foundation Model for Generalizable Disease Detection from Retinal Images

    PDF

    READING GUIDE

    RETFound performs self-supervised pretraining on large-scale unlabeled retinal images to learn general-purpose retinal representations, then transfers them to multiple disease detection tasks. Rather than training a separate classifier per disease, it begins to build a medical vision foundation model that serves many tasks.

    Key Takeaway

    The focus of medical AI research begins to shift from training a model for one task to learning general-purpose medical visual representations.

  4. 2026Nature Biomedical EngineeringCLEAR

    CLEAR: An Auditable Foundation Model for Radiology Grounded in Clinical Concepts

    PDF

    READING GUIDE

    CLEAR builds on a medical vision foundation model by introducing clinical concepts and an auditability mechanism, so that the model not only predicts disease but can also explain and have its evidence reviewed at the level of clinical concepts. It reflects the trend of medical foundation models moving from stronger generalization toward greater trustworthiness and auditability.

    Key Takeaway

    Medicine needs not only high-performance models, but also to know why a model made a judgment and whether it relied on sound medical evidence.

04

Medical Object Detection

4 papers

Detection here specifically means localizing and detecting lesions, nodules, tumors and other targets in medical images, rather than merely judging whether a disease is present. This section traces the progression from dedicated detectors designed for specific lesions, to general medical object detection frameworks, and on to language-vision models and medical vision foundation models.

Section Summary

Task-specific Lesion Detection → Self-configuring Detection → Language-driven Universal Detection → Biomedical Foundation Model: the focus moves from how to detect one particular lesion to how to build a general model capable of detecting previously unknown medical targets.

  1. 2019MICCAINoduleNet

    NoduleNet: Decoupled False Positive Reduction for Pulmonary Nodule Detection and Segmentation

    PDF

    READING GUIDE

    NoduleNet targets the high false-positive rate in pulmonary nodule detection by combining object detection with segmentation, using nodule morphology and boundary information to reduce false detections. It represents the typical task-specific model design of early medical lesion detection.

    Key Takeaway

    Medical object detection differs markedly from natural-image detection: lesions are usually small, faintly bounded and surrounded by similar tissue, so richer medical structural information must be incorporated.

  2. 2021MICCAInnDetection

    nnDetection: A Self-configuring Method for Medical Object Detection

    PDF

    READING GUIDE

    Following the philosophy of nnU-Net, nnDetection no longer hand-designs a detection network for each lesion type; instead it automatically configures preprocessing, network architecture and training strategy according to the characteristics of each medical dataset. It marks the transition of medical object detection from dedicated models to a general detection framework.

    Key Takeaway

    The research focus of medical object detection gradually shifts from designing complex detectors to establishing a general methodology that adapts to different data and tasks.

  3. 2024Medical Image Analysis

    Universal and Extensible Language-Vision Models for Organ Segmentation and Tumor Detection from Abdominal CT

    PDF

    READING GUIDE

    This work introduces language-vision representations, describing organ and tumor categories through language embeddings so that the model can extend to new categories while unifying organ segmentation and tumor detection. It exemplifies the move of medical vision tasks from fixed label sets toward language-driven, extensible models.

    Key Takeaway

    Once categories are described by language rather than fixed one-hot IDs, medical detection models begin to acquire far more flexible task interfaces.

  4. 2025Nature MethodsBiomedParse

    A Foundation Model for Joint Segmentation, Detection and Recognition of Biomedical Objects across Nine Modalities

    PDF

    READING GUIDE

    BiomedParse unifies segmentation, detection and recognition within a single medical vision foundation model covering multiple imaging modalities, making detection a basic capability of a general medical vision model. It marks the further integration of medical object detection into the foundation-model paradigm.

    Key Takeaway

    When a single foundation model can perform multiple vision tasks at once, traditional task boundaries dissolve, and medical AI shifts from task models toward general-capability models.

05

3D Reconstruction in Medical Imaging

4 papers

Reconstruction in this section specifically means building 3D anatomical targets — organs, vessels, the heart — from medical images, rather than classical MRI/CT image reconstruction. The research has progressed from 3D organ reconstruction based on 2D projections, to implicit 3D shape modeling, and further to personalized dynamic 4D structure generation and dynamic 3D reconstruction under sparse observations.

Section Summary

Single-view 3D Reconstruction → Implicit Shape Modeling → Personalized 4D Generation → Dynamic and Transferable Reconstruction: the core question is not recognizing what something is, but how to infer a not-directly-observable 3D human world from limited 2D observations. It naturally connects inverse problems, geometric deep learning, implicit neural representations and generative models.

  1. 2019IEEE TVCGDeepOrganNet

    DeepOrganNet: On-the-fly Reconstruction and Visualization of 3D/4D Lung Models from Single-view Projections

    PDF

    READING GUIDE

    DeepOrganNet rapidly recovers personalized 3D/4D lung models from single-view projections; its core idea is to learn the deformation from a standard anatomical template to an individual patient's structure. It shows that 2D medical observations, combined with anatomical priors, can recover 3D human structures that cannot be observed directly.

    Key Takeaway

    3D medical structure reconstruction is essentially a strongly prior-driven inverse problem: the model must exploit both image evidence and the regularities of human anatomy.

  2. 2022CVPRImplicitAtlas

    ImplicitAtlas: Learning Deformable Shape Templates in Medical Imaging

    PDF

    READING GUIDE

    ImplicitAtlas combines deformable anatomical templates with neural implicit representations, describing 3D organ and lesion shapes through continuous implicit functions and learning morphological variation across patients. Compared with traditional explicit mesh or voxel representations, it expresses complex 3D anatomical structures far more flexibly.

    Key Takeaway

    With the development of 3D generative techniques, medical structures no longer have to be represented by explicit voxels or meshes; implicit representations offer a new formulation for medical 3D shape modeling.

  3. 2025Nature Machine IntelligenceMeshHeart

    A Personalized Time-resolved 3D Mesh Generative Model for Unveiling Normal Heart Dynamics

    PDF

    READING GUIDE

    MeshHeart learns personalized 3D cardiac meshes from large-scale cardiac MRI data and further models the dynamics over a complete cardiac cycle, generating personalized, time-resolved 3D heart structures. It extends medical 3D reconstruction from static structures to dynamic human-body modeling.

    Key Takeaway

    Medical 3D structures have not only a spatial dimension but also a temporal one; future anatomical modeling must describe both form and motion.

  4. 2025Nature Machine Intelligence

    Sparse and Transferable Three-dimensional Dynamic Vascular Reconstruction for Instantaneous Diagnosis

    PDF

    READING GUIDE

    This work constructs dynamic 3D vascular structures under sparse medical observations, with emphasis on transferability across scenarios. The goal expands from reconstructing a static 3D target to recovering dynamic, transferable 3D human structures when information is incomplete.

    Key Takeaway

    The core difficulties of future 3D reconstruction lie not only in structural representation, but also in limited observations, dynamic change, and generalization across patients and scenarios.

06

Medical Image Agents

4 papers

Medical image agents represent the further evolution of medical AI from models to systems. The core is no longer a single model performing a fixed task, but an AI that understands problems, invokes medical tools, orchestrates multiple models, executes multi-step tasks and finally forms an integrated decision. This section follows the path LLM + CAD → Tool-use Agent → Multi-Agent → Autonomous Scientific Agent.

Section Summary

LLM + CAD → Tool-use Agent → Multi-Agent Workflow → Autonomous Scientific Agent: AI evolves from a model into a system that can use models. While the previous five sections address specific capabilities — classification, detection, segmentation, generation and 3D reconstruction — agents organize these capabilities so that AI can perceive, reason, plan, call tools, execute, verify and decide, ultimately moving toward autonomous medical scientific discovery.

  1. 2024IEEE TMIChatCAD+

    ChatCAD+: Toward a Universal and Reliable Interactive CAD Using LLMs

    PDF

    READING GUIDE

    ChatCAD+ uses a large language model as the unified interaction and reasoning hub of a medical-imaging CAD system, connecting existing image-analysis models to deliver diagnosis, report generation and interactive question answering. It represents an early exploration of coupling LLMs with specialist medical vision models.

    Key Takeaway

    Medicine has already accumulated a large stock of specialist classification, detection and segmentation models; an important value of LLMs is to organize these scattered capabilities.

  2. 2024EMNLPMMedAgent

    MMedAgent: Learning to Use Medical Tools with Multi-modal Agent

    PDF

    READING GUIDE

    MMedAgent treats different medical vision models as callable tools, allowing the agent to autonomously select the appropriate tool for a user's request and complete multimodal medical tasks — classification, segmentation, grounding, question answering and report generation. Compared with ChatCAD+, it further emphasizes the agent's autonomous tool-use ability.

    Key Takeaway

    Tool use is a key dividing line between a medical assistant and a medical agent: the agent no longer merely integrates results, but begins to decide autonomously what to do next.

  3. 2025ICCVPathFinder

    PathFinder: A Multi-modal Multi-agent System for Medical Diagnostic Decision-making Applied to Histopathology

    PDF

    READING GUIDE

    PathFinder decomposes the pathological diagnostic process into multiple collaborating specialist agents — case selection, region navigation, image description and diagnosis — enabling AI to mimic the workflow of a pathologist progressively browsing and analyzing a whole-slide image.

    Key Takeaway

    The value of a multi-agent system lies not only in having multiple models work together, but in decomposing a complex medical task into subtasks with distinct responsibilities.

  4. 2026Nature Medicine

    An Agentic Framework for Autonomous Scientific Discovery in Cancer Pathology

    PDF

    READING GUIDE

    This work further extends agent capabilities from clinical diagnosis to cancer pathology research, allowing agents to participate in data analysis, pattern discovery, hypothesis construction and scientific validation. The role of AI shifts from helping doctors complete tasks to helping scientists conduct research.

    Key Takeaway

    The ultimate value of an agent may not be replacing any single medical model, but organizing perception, reasoning, tool use and scientific analysis into a system capable of autonomously executing complex tasks.
