Architecture

它是如何工作的：三层架构

设计原则只有一条：LLM 只做它擅长的事，其余交给不会说谎的管线。

协议层 · 科研级严谨（包裹全局）

智能体层 · 八角色会诊链

有人看片，有人算数，有人翻旧病例，有人专门唱反调，最后有人拍板——像一场医院里的多学科会诊。

证据层 · 确定性计算（不经 LLM）

FreeSurfer / SynthSeg 分割 → 20 余项指标 → 以 ADNIMERGE2 常模队列（825 例认知正常者）校正出 z 分数 → 标准化影像包。

  • 真值标签物理隔离
  • 泄漏拒答防线
  • 5 折分层评测
  • 失败计入分母
  • 全链路审计 JSON
  • bootstrap 置信区间

证据层 · 确定性计算，不经 LLM

FreeSurfer / SynthSeg 完成脑区分割，产出 20 余项脑区体积与皮层厚度指标；再以 ADNIMERGE2 常模队列为参照，计算经年龄、性别、颅内容积校正的 z 分数，并做 FreeSurfer 版本间映射校正。同时自动生成标准化影像包：海马冠状位三联图、全局轴位图、矢状位图、区域 z 分数热图与百分位图。LLM 看到的每一个数字，都先经过这条确定性管线。

智能体层 · 八角色会诊链

八个各司其职的智能体依次接力：QC 质检 → 视觉评分（MTA / GCA / Koedam）→ 定量解读 → 相似病例检索（留一折防泄漏）→ 定向知识卡 → 初步分期 → Critic 批判复核 → 决策校准。

协议层 · 科研级严谨

真值标签物理隔离，模型全程接触不到答案，并设泄漏拒答防线；5 折分层评测，每位受试者仅入组一例；推理失败计入分母，不粉饰覆盖率；每例生成全链路审计 JSON 留痕；总体指标附 bootstrap 置信区间。

八角色链 · 输入输出详版

1QC 质检图像/指标可用性
2视觉评分只看图 · MTA/GCA/Koedam
3定量解读只读 z 分数报告
4病例检索留一折防泄漏
5知识卡诊断指南要点
6初步分期唯一有权出标签
7Critic 复核按清单核查
8决策校准折算最终判断

Highlights

为什么值得一看

零训练

零训练、零微调，纯靠 LLM 推理链 + 影像量化管线。换一个底层模型即插即用，没有任何昂贵的再训练成本。

双模型同场对照

DeepSeek-Vision 与 GPT-5.6 跑完全相同的流程，消融实验逐一归因——哪个组件有用、哪个是拖累，全部用数据说话。

反直觉的发现

多角色链反而不如单 Agent；Critic 在较弱的模型上「越审越错」；最大单项收益来自决策层校准（最高 +14 个百分点）。

诚实的工程

失败案例计入分母、标签泄漏防线、改判全程审计、错误模式分类（以 E-AMB 交界混淆为主）。我们汇报的是系统真实的样子。

完整在线可查

每一例都可以查看标准化影像包、量化报告与八角色完整审计链——每个结论都能追溯到它的每一步推理。

Findings

我们发现了什么：三个反直觉的结论

发现一

角色越多 ≠ 越准

完整八角色链的裸成绩（48.7% / 40.7%）反而低于精简的单 Agent 配置。多角色带来了制衡与可解释性，也带来了信息传递中的损耗与噪声——复杂度本身不是免费的。

发现二

Critic 在弱模型上「越审越错」

批判复核环节的价值高度依赖底层模型能力：能力不足时，Critic 不仅挑不出真问题，还会把原本正确的判断改错。给系统加「审查员」之前，先确认审查员真的更高明。

发现三

最大的收益来自决策校准

消融中最大的单项增益（最高 +14 个百分点）既不来自更多图像、也不来自更多角色，而来自决策层的校准——如何把已有证据折算成最终判断。证据早就够了，是决策方式在浪费证据。

诚实声明

本系统仅使用 MRI 与人口学信息，未使用任何认知量表；150 例属小样本评测。56% 已接近该信号源在三分类任务上的天花板。系统定位是辅助评估研究原型与课程教学示例，不构成临床诊断，不得用于任何医疗决策。
