AD 作业数据集下载

本数据集包含 150 例受试者（CN / MCI / AD 各 50 例），每例包含一份 T1 加权脑部 MRI 与年龄、性别信息，并附真值标签供自评。数据源自公开研究队列（ADNI，待按实际来源核对），经课程组整理与匿名化处理，仅限本课程教学使用。

使用条款（勾选后方可下载）

  1. 数据仅限《科学人工智能》课程学习使用；
  2. 禁止以任何形式再分发，禁止上传至任何公开平台（包括代码仓库、网盘分享、模型训练平台）；
  3. 禁止尝试识别受试者身份；
  4. 若课程成果对外发表，须按课程组提供的格式注明数据来源（引用格式待补充）。
  • 推荐

    NIfTI 原始格式包

    150 例 .nii.gz 原始体数据 + participants.csv（编号 / 年龄 / 性别 / 标签）。适合完整复现从分割、量化到诊断的全流程，是与示例 Demo 一致的输入格式。

    体积约 XX GB（待补充）

  • PNG 切片格式包

    每例预先导出的轴位 / 冠状位 / 矢状位关键切片（含海马层面）。适合暂不方便运行 FreeSurfer / SynthSeg、想先从视觉-语言模型路线入手的同学。注意：切片包含的信息少于原始体数据。

    体积约 X GB（待补充）
