v1 · Baseline（朴素版）

把所有信息，一股脑喂给一个 LLM

v1 将量化数据、图像与人口学信息合并输入单条 LLM 链（外加四个 3D CNN 模型通道投票），一次性要求输出结论。结果只比随机猜好一点：信息在长上下文中被互相稀释，模型顾此失彼。我们保留了完整运行记录，作为对照组与反面教材。

150 例三分类正确率

0%

随机地板 33.3%

它是怎么做的

SynthSeg + FreeSurfer 双工具分割量化，四个 3D CNN（MedicalNet / ResNet-18/34/50）同场投票，六角色 LLM 链一次走完：

1编排器证据清点
2初诊医生首次判断
3指南核查RAG
4鉴别诊断
5质询医生挑毛病
6定稿医生综合结论
病灶所在：70 余项脑区裸体积（毫升数，无年龄/性别参照系）+ 低分辨率大拼图 + 双工具互相矛盾的数据，全部平铺进一次长上下文调用——每个角色单独看都「合情合理」，合在一起却系统性失准。
