第七课

AD 诊断系统是怎么想出来的

小明和小灵接到了一份课程设计：只用脑部核磁、年龄和性别，判断一个人是 CN、MCI 还是 AD。他们一路问 LLM 小伙伴，一路摔跟头，从 34% 走到了 56%。这一课，讲的就是这一路。

学习目标：读懂课程要求 → 认识 AD → 理解证据表征为什么比 Agent 数量更重要
  • 小明点子多、爱画架构图，相信“多多益善”。
  • 小灵细心、爱追问，总能从问题里揪出根因。
  • LLM 小伙伴有问必答，也会犹豫和提醒；是他们的编程与医学顾问。

一、接到任务

（教室/书桌前，两人翻看课程设计任务书）

  1. 01小明

    小灵！这学期的课程设计题目下来啦——「基于 AI 的阿尔茨海默病（AD）诊断系统」。

  2. 02小灵

    我看看要求……哇，老师特别写了一条：不许训练模型，要用 LLM 和 Agent 的思路来解决。

  3. 03小明

    数据我们是有的：150 个病人的脑部核磁（MRI），每人一个诊断标签——CN（认知正常）、MCI（轻度认知障碍）、AD（阿尔茨海默病）三类，另外还有年龄、性别这些基本信息。

  4. 04小灵

    所以任务本质上是个三分类：给一份新的 MRI，系统要判断这个人属于 CN、MCI 还是 AD，最后按准确率来评价。

  5. 05小明

    等等，先别急着设计系统。AD 到底是一种什么病？我只知道会「忘事」。

  6. 06小灵

    这个别瞎猜，问问 LLM 吧。

  7. 07LLM 小伙伴

    AD 是最常见的神经退行性痴呆。异常蛋白在大脑里逐渐堆积，神经元慢慢死亡，负责记忆的海马和它周围的内侧颞叶通常最先萎缩。它是一个连续的过程：认知正常（CN）→ 轻度认知障碍（MCI）→ 痴呆阶段（AD）。

  8. 08小明

    哦！所以我们的三分类，其实是在给「同一条下坡路」分段？

  9. 09小灵

    难怪 MCI 夹在中间——它是过渡地带，听起来就最难分。那真正的医院里，医生是怎么确诊的？也是只看核磁吗？

  10. 10LLM 小伙伴

    不是，临床诊断是一整套组合拳：问病史，做认知量表（比如 MMSE 记忆测验），查生物标志物（抽血或 PET），MRI 主要负责看萎缩的模式——放射科医生会在标准位置给内侧颞叶萎缩打一个 MTA 分（0 到 4 分），同时排除肿瘤、脑血管病这些其它原因。

  11. 11小明

    糟糕。量表、PET、病史……这些我们一样都没有，手里只有 MRI 加年龄性别。

  12. 12小灵

    别慌。医生看片子能看出萎缩，说明 MRI 里是有信息的。我们的任务，就是想办法让 LLM 把这份信息「读」出来。

本节要点

课程要求、AD 是什么、临床如何诊断、发现手头证据有限

情绪基调：好奇、略担忧

二、最直接的想法——把片子扔给 LLM

（电脑前，屏幕上是 MRI 切片）

  1. 13小明

    那还不简单！LLM 不是号称能看图吗？把 MRI 切片直接发给它：「请诊断，三选一」！

  2. 14小灵

    说干就干。我挑一个病例：6 张不同角度的脑部切片，加一句「65 岁，女性」。发送！

  3. 15小明

    它在看了它在看了……

  4. 16LLM 小伙伴

    嗯……从图上看，海马形态还算饱满，双侧大致对称，脑室和颞角没有明显扩大……我倾向于 CN。但我得提醒两句：第一，MCI 本质上是临床诊断，仅凭 MRI 很难可靠区分 CN 和 MCI；第二，你们给我的是原始图像和绝对数值，缺少「65 岁女性应该长什么样」的参照，我没法确定这算不算萎缩。

  5. 17小灵

    可是……这个病例的真实标签是 AD。答错了。

  6. 18小明

    多试几个看看……它几乎每次都在 CN 和 MCI 之间摇摆，动不动就「无法排除早期病变」「建议结合临床」。

  7. 19小灵

    批量跑了一遍，正确率跟扔骰子差不多。「把片子扔给 LLM」这条路，直接堵死了。

  8. 20小明

    奇怪啊，医生看一眼能发现的东西，LLM 为什么看不出来？是它太笨，还是我们问的方式不对？

  9. 21小灵

    别自己闷头猜了，问它：学术界有没有人用 LLM Agent 做过 AD 诊断？人家是怎么做的？

本节要点

直接把 MRI 丢给 LLM，答非所问、接近随机

情绪基调：兴奋→受挫

三、查文献，搭一支「AI 会诊团」

（翻论文/查资料的画面）

  1. 22LLM 小伙伴

    还真有几篇代表作。Zhang 2026：让 9 个单维度 Agent 加 5 个高级 Agent 开「多学科会诊」，在 1362 条 ADNI 数据上三分类 F1 做到了 88%。ADAgent：用 LLM 当协调者去融合各路证据，比简单的平均融合、多数投票都更准。MedAgent-Pro：把「诊断规划、量化分析、证据推理」分层，一步步把裸大模型的准确率从 56 提到 90。

  2. 23小明

    88%！那我们照着抄不就行了？！

  3. 24小灵

    等等，我有个疑问——这些论文里，MRI 到底是怎么交给 Agent 的？也是像我们这样把图直接发过去吗？

  4. 25LLM 小伙伴

    这个问题问到点子上了。都不是直接看图。比如 Zhang 那篇，MRI 先经过一个训练好的视觉编码器变成特征，Agent 拿到的是加工后的结论；而且它 88% 的主要功劳来自 MMSE、CDR 这些强临床量表——单看 MRI 那一路，F1 只有 50% 出头。

  5. 26小明

    也就是说，「论文用了 MRI」不等于「LLM 直接看 MRI」——中间都隔着一层把图像变成证据的加工！

  6. 27小灵

    那我们也别让 LLM 裸看图了！可以用现成的医学分割工具——SynthSeg、FreeSurfer——先把大脑各区域的体积量出来，再把数字交给 LLM 去推理。工具是现成的，不算「训练模型」，不违反老师的要求！

  7. 28小明

    好，我来画架构：分割工具输出体积表 → 「鉴别诊断 Agent」提出候选 → 「批判 Agent」专门挑毛病 → 再配一个诊断指南知识库（RAG）随时查标准 → 最后「协调 Agent」拍板。一支 AI 会诊团！

  8. 29小灵

    SynthSeg 和 FreeSurfer 干脆都用上吧，两个工具互相印证，证据丰富一些！

  9. 30LLM 小伙伴

    提醒一句：第一版最好先跑通「一个分割工具 + 一个诊断 Agent」的最小闭环，确认证据有效，再往上加。工具全都上，项目容易变成「分割软件大合集」。

  10. 31小明

    多多益善嘛！证据越多越稳，全都上！

  11. 32小灵

    跑起来了……150 个病例，一例一例过……

本节要点

三篇文献、关键提问「MRI 怎么给 Agent」、多 Agent 架构、加法思维

情绪基调：重燃希望

四、34%——和抛硬币一样

（屏幕上一个刺眼的「34%」，两人愁云惨淡）

  1. 33小明

    结果出来了……三分类正确率——34%。

  2. 34小灵

    34？！三个类别闭着眼瞎猜都有 33.3%！我们搭了整整一支会诊团，效果约等于随机数生成器？？

  3. 35小明

    先别崩溃，是不是哪里写错了？标签映射、数据读取、Agent 之间的传参……我们把流程逐行查一遍。

  4. 36小灵

    ……查完了，没有 bug。每个 Agent 单独看都工作正常，输出都「合情合理」，可合在一起就是不对。

  5. 37小明

    （托腮）会不会是 Agent 还不够多？要不……再加一个更严格的审核 Agent？

  6. 38小灵

    （摇头）不对劲。你想：如果证据本身没有信号，再多 Agent 开会，也只是把随机结果讨论得更热闹而已。问问 LLM 该怎么排查。

  7. 39LLM 小伙伴

    我的建议是——现在先不要加任何 Agent，给你们的系统做一次「体检」。最简单的一步：挑一个病例，把你们喂给系统的东西原封不动发给我，看看我这个「裸 LLM」拿到手会怎么读。

  8. 40小明

    好，就用那个 65 岁女性：一张 6×6 的切片拼图，加上 SynthSeg 的体积表——左海马 4.9 毫升，右海马 5.1 毫升……70 多个脑区的数字全给你。请诊断。

  9. 41LLM 小伙伴

    老实说……「左海马 4.9 毫升」——我不知道这个数对 65 岁女性来说算不算小。海马体积本来就随年龄、性别、头颅大小而变化，没有参照系，我只能看图「感觉还饱满」，然后出于医学上的谨慎报一个 CN。还有，你们这张 6×6 拼图，每个小格只剩百来个像素——海马那么小的结构，我是真的看不清。

  10. 42小灵

    等一下！！我好像明白了！问题根本不在 Agent 的编排——在我们喂给它的证据本身！

  11. 43小明

    对啊！医生说「海马萎缩」，从来不是说「海马 4.9 毫升」，而是「比同龄人明显小」。我们把裸体积扔给 LLM，等于给一个不知道及格线的人报分数，让他判断及不及格！

  12. 44小灵

    顺着这个思路，把系统里的证据挨个过一遍——我们至少踩了四个坑。

  13. 45小明

    坑一：裸数字没有参照系。不带年龄性别校正，LLM 无从判断体积是高是低。

  14. 46小灵

    坑二：两个工具在打架。SynthSeg 和 FreeSurfer 对同一个脑袋量出来的颅内体积能差 30%，颞角体积能差两倍。我们把两份互相矛盾的表都丢了进去，让 LLM 自己看着办——等于往证据链里灌随机噪声。

  15. 47小明

    坑三：图不可读。大拼图每格分辨率太低，内侧颞叶的裁剪框甚至没框住海马——我们发的其实是一堆马赛克。

  16. 48小灵

    坑四：会诊团在和稀泥。鉴别 Agent 和批判 Agent 一轮轮讨论，越「谨慎」结论越往中间靠——三分类的中间是谁？MCI。所以系统动不动就报 MCI，把「不确定」当成了一个类别。

  17. 49小明

    难怪 MedAgent-Pro 的消融实验里，最大的提升来自拿到真实的量化证据，而不是「多叫几个大模型开会」。我们光顾着抄它的多 Agent，没抄到它的重点。

  18. 50小灵

    那关键问题来了——一个人类专家，如果也像我们一样只有 MRI 和年龄性别，他会怎么诊断？

  19. 51LLM 小伙伴

    他会做两件事。第一，他脑子里有一套常模：几十年的读片经验让他知道「65 岁女性的海马该长什么样」，所以他给出的从来是相对判断——「萎缩程度超出了这个年龄该有的水平」。第二，他不会平铺 36 张缩略图，而是在标准位置仔细看关键结构——比如内侧颞叶的冠状位，然后打一个 MTA 评分。你们要做的，就是把这两件事变成流程：给数字造一个参照系，给图像一个医生式的看法。

  20. 52小明

    给数字造参照系，给图像医生式的看法……小灵，我感觉这次摸到门了！

本节要点

冥思苦想、单例体检实验、四个坑、根因＝证据表征

情绪基调：低谷→顿悟

五、重做证据——让 LLM 拿到「读得懂的报告」

（白板/流程图画面，两人重构系统）

  1. 53小灵

    参照系从哪来？用我们自己这 150 例算平均值肯定不行——里面混着 AD 患者，算出来的「正常值」本身就偏低，会系统性低估萎缩。

  2. 54小明

    去公开数据库找！ADNI 有上千名健康老年人的量化数据（ADNIMERGE 表）。我们用健康对照拟合一条回归线：脑区体积 ~ 年龄 + 性别 + 颅内体积。

  3. 55小灵

    然后把每个病例的每个脑区都换算成 z 分数：观测值减去「同龄同性别的预期值」，再除以正常波动范围。报告里写的就不再是「左海马 4.9 毫升」，而是——「左海马 z = −2.1，低于同龄同性别的第 2 百分位」。

  4. 56小明

    这句话 LLM 一定读得懂！它有海量医学文献打底，「低于第 2 百分位」对它来说是有含义的证据；「4.9 毫升」只是一个陌生的字符串。

  5. 57小灵

    不过，70 多个脑区都算出 z 分数然后全丢进去，LLM 会不会又淹死在数字里？

  6. 58LLM 小伙伴

    会，所以要帮它划重点。按解剖分组算复合分数：内侧颞叶组、外侧颞叶组、后部皮层组、额叶组、脑室组，组内取平均，统一让「异常」方向为正。再加两个医生爱用的巧指标：HOC（海马占位系数，一个数同时捕捉海马缩小和颞角扩张）和左右不对称指数。正文只保留 15 到 25 个最有临床意义的数字，其余全放附录。

  7. 59小明

    图像也重做！扔掉大拼图，改成三套标准化视图：全脑概览、双侧内侧颞叶放大的冠状位、后部皮层视图。分辨率提上去，每次最多发 4 张。

  8. 60小灵

    而且所有病人都用同样的标准位置切图——不许人工挑「看起来最像 AD」的切片，不然就是我们自己往里漏答案了。

  9. 61小明

    两个工具打架的问题也立个规矩：颅内体积冲突超过 10% 时，只用 FreeSurfer 的做分母，同时打一条 QC 警告。用明确的规则裁决，不能让 Agent 自己「讨论」着办。

  10. 62小灵

    还有会诊团和稀泥的毛病。我有个想法：别让 Agent 们围着圆桌辩论了，改成流水线——一个接一个来，各管一段，权限锁死。

  11. 63小明

    顺序我来排！最前面放 QC Agent 检查数据质量；然后视觉 Agent 只看图，打 MTA 这类视觉评分，不许看数字，免得被数字带偏；接着定量 Agent 只读 z 分数报告，也看不到视觉 Agent 的结论；再查相似病例和诊断指南；最后，Staging Agent 是全场唯一有权说出 CN/MCI/AD 的角色。

  12. 64小灵

    批判 Agent 保留，但是降权：它拿着核查清单逐项检查证据链条一致不一致，无权修改诊断。这样「谨慎」就再也没法把结果往 MCI 推了。

  13. 65LLM 小伙伴

    这套设计我要点赞——顺序执行 + 权限隔离，每个角色的输入输出都可审计。文献也站在你们这边：Zhang 那篇的分阶段实验里，「逐项核查」的校验阶段是全流程单次提升最大的一步（一步提了 24 个百分点）——但前提正是按清单核查，而不是泛泛地说一句「请批判一下」。

  14. 66小明

    好！证据、图像、架构，全部重构完毕……重新跑！150 例，按患者分层五折评估，测试集这次一根手指头都不碰……

  15. 67小灵

    紧张紧张紧张……上次是 34，这次哪怕到 45，我都心满意足了……

本节要点

z 分数常模、复合指标、标准化切片、顺序执行+权限锁定

情绪基调：专注、有条理

六、56%！

（屏幕上跳出「≈56%」，彩带庆祝）

  1. 68小明

    出来了出来了！！平衡准确率——接近 56%！！

  2. 69小灵

    从 34 到 56，二十多个百分点！！而且 CN 和 AD 之间分得特别开！

  3. 70小明

    最妙的是什么？我们一个模型都没训练，一个 Agent 都没多加——从头到尾改变的，只有「喂给 LLM 的证据长什么样」！

  4. 71小灵

    不过……56% 拿去答辩，老师会不会嫌低啊？论文里可是动辄 88%……

  5. 72LLM 小伙伴

    这就要算一笔「信息上限」的账了。那些 88% 靠的是认知量表、PET、基因这些强证据——你们一样都没有。在「只有 MRI + 年龄 + 性别」这个条件下：国际竞赛 CADDementia 上 29 个算法的最好成绩是 63%；Zhang 那篇单看 MRI 的一路，F1 也只有 50% 出头。所以 56% 不是「才 56%」，而是已经接近这份数据本身能给出的上限。

  6. 73小明

    懂了，这正是答辩要讲清楚的一层：模型的能力差和数据的信息差，是两回事。

  7. 74小灵

    所以我们的研究问题也应该升级——不是「LLM 能不能诊断 AD」，而是「不同层次的证据表征，能不能提升 LLM Agent 的诊断能力」。

  8. 75小明

    而我们用实验给出了答案：同一套 Agent 架构，把证据从「一堆毫升数 + 一张马赛克拼图」换成「年龄性别校正的 z 分数 + 医生式的标准化切片」，准确率就从随机水平升到了接近上限。

  9. 76小灵

    回头看，我们摔的每一跤都值：直接扔图，学到「LLM 不是读片机」；34% 那次，学到「证据表征比 Agent 数量重要」；重做表征，学到「要给 LLM 一份读得懂的报告」。

  10. 77小明

    一句话总结带走：决定成败的，是证据表征的质量，不是 Agent 的数量。

  11. 78小灵

    LLM 不是一台机器，它更像一位读报告的医生——我们的工作，是替它写出那份读得懂的报告。课程设计，收工！

  12. 79LLM 小伙伴

    恭喜你们！随时再来找我聊～

本节要点

34→56、信息上限、研究问题升级、方法论总结
